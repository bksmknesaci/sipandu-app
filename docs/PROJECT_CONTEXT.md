# SIPANDU - Project Context

## Nama Project

SIPANDU (Sistem Informasi dan Penanganan Siswa Terpadu)

## Deskripsi

Aplikasi berbasis web untuk pengelolaan data siswa, guru, pelanggaran, prestasi, bimbingan konseling, dan laporan sekolah.

## Tech Stack

Frontend:

* Next.js
* TypeScript
* Tailwind CSS

Backend:

* Supabase

Database:

* PostgreSQL (Supabase)

Authentication:

* Supabase Auth

Deployment:

* Vercel

Repository:

* GitHub

Editor:

* VS Code
